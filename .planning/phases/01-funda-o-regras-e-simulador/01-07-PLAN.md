<interfaces>
Contratos do simulador (usados pelo plano 08):

class_name Perfil extends RefCounted  (simulador/perfis.gd define Perfil, PerfilPerfeito, PerfilAprendiz como classes internas ou arquivos próprios com class_name)
- func decidir(partida: Partida, rng: RandomNumberGenerator) -> Dictionary
  retorno: {"acao": "jogar", "carta": int, "palavra": int, "espaco": int} ou {"acao": "trocar"}
- PerfilPerfeito: primeira carta da mão do mago atual que casa com algum espaço aberto (varrendo cartas e depois palavras e espaços em ordem); senão trocar
- PerfilAprendiz: igual ao perfeito, porém, quando haveria jogada, com probabilidade partida.cfg.taxa_erro_aprendiz usa o mesmo carta num espaço ABERTO de sílaba diferente (sorteado com o rng); se não existir espaço aberto de sílaba diferente, joga o correto; se o perfeito trocaria, troca

class_name Simulacao extends RefCounted
- static func rodar(cfg: ConfigRegras, bib: BibliotecaPalavras, dist: DistribuicaoBaralho, n_magos: int, perfil: Perfil, n_partidas: int, semente: int) -> Dictionary
  chaves do retorno: n_magos, perfil (String), partidas, terminadas, pct_terminadas, turnos_partida (media, mediana, p95), turnos_por_mago_media, pct_turnos_sem_ponto, pct_turnos_troca, pct_turnos_erro, pct_partidas_mago_zerado, pontos_medios_por_mago, por_palavra (Dictionary texto -> {aparicoes, turnos_ate_completar_media, vezes_ultima})
- Definição de turno: o turno termina quando Partida.turnos_jogados aumenta; é "com ponto" se houve ACERTO nele; senão é "sem ponto" com causa = última ação do turno (TROCOU => troca; ERRO => erro). O último turno de uma partida concluída conta como com ponto. Partidas que passam de cfg.limite_turnos_partida ações são "não terminadas".
- Cada partida usa um RandomNumberGenerator próprio com seed derivada de (semente, índice da partida, n_magos); nunca RNG global.

class_name Relatorio extends RefCounted
- static func montar(cfg: ConfigRegras, semente: int, resultados: Array) -> String   (markdown/texto)
- static func metas_ok(resultados: Array) -> bool                                   (D-18, D-19, D-20 sobre os resultados do perfil perfeito)
</interfaces>
</context>
